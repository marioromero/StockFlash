# stockflash-ui-guard


Leer contrato de marca. Reusar componentes de UI, escala tipográfica, tokens de espaciado y estados. Navegación de backoffice por sidebar colapsable. Evitar dependencias nuevas sin aprobación. Pruebas de teclado/tabulador, foco, contraste, vacíos, carga, error, tablet y desktop; objetivos touch mínimo 44px. No sobrecargar vistas ni inventar 7 estilos independientes.
