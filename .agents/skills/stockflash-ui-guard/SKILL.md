# stockflash-ui-guard

Use shared corporate tokens/components and the approved brand contract. Avoid unexplained dependencies or multiple separate design systems. Check keyboard/tab, focus, contrast, error/empty/loading states, tablet/desktop and touch targets >=44px where applicable. Keep visible UI labels es-CL. Read only changed screens and their components.
