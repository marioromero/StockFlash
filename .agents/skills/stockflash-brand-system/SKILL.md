# stockflash-brand-system

When UI changes, consult brand contract, module identity map and asset inventory in that order; do not load full branding docs otherwise. Prefer official PNG when listed as official; otherwise use approved text fallback plus active product label. Colors #303846, #0856FF and #03C6BE require contrast. Do not recreate logo in CSS or invent palettes. Verify desktop/tablet and visible product label, report missing art without downloading unapproved assets.
