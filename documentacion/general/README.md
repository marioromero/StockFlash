# Introducción a StockFlash

StockFlash es un sistema modular de punto de venta (POS) y gestión comercial para el comercio chileno. Se vende por módulos independientes que se activan según la licencia contratada: POS, Bodega, SyncWP, Fiscal, Compras, Analítica y Control.

## Cómo navegar este manual

- Busca por **módulo** en la carpeta `modulos/` si ya sabes a qué producto pertenece la función que buscas.
- Usa la carpeta `general/` para funciones transversales que aplican a varios módulos (por ejemplo, inicio de sesión, cambios de contraseña, perfiles de usuario).
- Cada guía tiene un nombre descriptivo y enlaces relativos para moverse entre temas relacionados.

## Cómo usar una guía

Cada guía responde, en orden:

1. **Para qué sirve la funcionalidad.**
2. **Quién puede usarla** (roles y permisos).
3. **Cómo acceder** (ruta en la interfaz).
4. **Cómo utilizarla** (paso a paso, con nombres reales de botones, menús y campos).
5. **Opciones y configuraciones disponibles.**
6. **Reglas y limitaciones** (qué permite y qué impide el sistema).
7. **Resultados esperados.**
8. **Errores frecuentes y soluciones.**
9. **Ejemplos prácticos.**

## Funciones transversales

Algunas acciones están disponibles desde cualquier módulo:

- Cambio de contraseña de usuario.
- Cierre de sesión.
- Selección de sucursal (cuando el usuario tiene acceso a más de una).

## Limitaciones generales

- StockFlash no emite documentos fiscales por sí solo sin el módulo Fiscal habilitado y configurado.
- El módulo Control es de administración privada (clientes, licencias, suscripciones) y no se vende como producto independiente.
- Caja, Clientes y Precios son funciones internas del sistema, nunca productos vendidos por separado.
