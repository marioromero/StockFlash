- `clearRutSearch` (`:174-179`) forgets the session hash and redirects clean.
- Routes (`routes/web.php:322-328`) place `POST /customers/rut-search` and `POST /customers/rut-search/clear` behind `customers.module` + `customers.view`.
- UI (`Index.vue:76-111`, `:457-515`) uses a separate POST form, never adds `rut` to GET filter params, clears `rutTerm` after success, and shows the active-filter notice/clear action.

**Targeted evidence**
- `CustomerRutSearchPrivacyTest` + `CustomerListTest`: **12 passed / 305 assertions**.
- Full-body proof: valid POST (`rut=0006000000-K`) → 302 `/customers`; `Location` has no `rut=`/`6000000`; POST body no variants; redirected full HTML/`data-page` no variants; props contain `filters.rut_filter=true` but no `filters.rut`, no hash; session stores only the 64-hex HMAC of `6000000-K`; session JSON contains no submitted variant.
