2. Leer exclusivamente estas nueve claves de `system_configs`; los datos de responsable son personales: auditoría de lectura antes de exponerlos, sin copiar valores; error de auditoría bloquea la lectura.
3. Formularios con datos opcionales, validación técnica de tipos/tamaños y correo si se proporciona. No afirmar que el RUT ha sido validado ante SII ni que se emiten DTE. Solo persistir claves allowlist, normalizar vacío a null; metadatos y demás filas intactas. No inventar obligatoriedad previa a onboarding.
4. Auditoría de cambios y escritura atómicas: registrar actor, fecha y nombres de claves modificadas, **nunca contenido anterior/nuevo ni datos personales**; fallo revierte todo. Si nada cambia, no generar escritura ni log de cambios.
5. Reutilizar el guard RN-70 de solo lectura cuando licencia esté suspendida fuera de gracia. Mantener PATCH deshabilitado para evitar actualizaciones parciales.
6. Tests: GET/PUT autorizados, 403 sin permiso, auditoría lectura PII fail-closed, validaciones, extras ignorados sin escritura ajena, rollback, RN-70, PATCH 405, no cambios y regresión de CFG-001/USERS/BRANCH/AUTH; suite completa PHP, TS, Vite, contratos.
