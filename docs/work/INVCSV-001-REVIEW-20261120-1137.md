## Findings (all non-blocking)
- **F1 — MINOR (parser leniency).** A syntactically malformed quoted field with an even quote count, e.g. `"A4"x;1.000`, is normalized by `fgetcsv` to SKU `A4x` rather than rejected (`InitialStockCsvParser.php:143-149,196-204`; probe result). No injection/leak/partial write: the normalized SKU still must match an eligible catalog variant exactly and quantity is strictly validated. Packet wording “malformed quoting rejected fail-closed” is not literally complete for this edge. Recommend a follow-up strict quote-state check; no correction cycle required for acceptance.
- **F2 — MINOR (BOM + quoted header).** `\xEF\xBB\xBF"sku";"cantidad"` is rejected because the BOM precedes the opening quote, so `fgetcsv` does not treat the first field as quoted (`InitialStockCsvParser.php:157-174`; probe). This is fail-closed and the generated template (BOM + unquoted header) works, but an Excel “quote all” + BOM export fails with a confusing header error. Recommend stripping BOM before parsing/delimiter detection in a follow-up.
- **F3 — HARDENING (resolver parity).** Controller resolves `1E0` identically to `EnsureBranchAccess` and the regression passes on SQLite, but it uses `(int)$identifier` while middleware passes the raw token to `whereKey()` (`InitialStockImportController.php:198-202`). With fractional numeric branch codes (e.g. `1.5`) in legacy data the two could diverge. `BranchRequest` restricts codes to `^[A-Z0-9-]+$` (`BranchRequest.php:62`), so this is unreachable via the application; MariaDB coercion NOT_RUN. Recommend sharing the exact resolver later.
- **F4 — PROCESS RESIDUAL (not a code defect).** Per the owner directive, the remote database remains a known historical exception and is **NOT** claimed UNTOUCHED; no cleanup is authorized. QA performed **no remote DB access**. The candidate notes carry the truthful non-UNTOUCHED status (`INVCSV-001-NOTES-20261120.md`).
- **F5 — TEST GAP.** No direct test for the ambiguous-duplicate-SKU branch or for even-quote malformed input (F1); the formula-injection assertion is weak (inputs never contain `<script>`). Code paths exist; not acceptance-blocking.
- **F6 — UI BROWSER RISK (deferred).** Preview is a POST returning a 200 Inertia page (`InitialStockImportController.php:65-82`); Inertia will push `/import/preview` into history. A browser refresh on that URL is a GET against a POST-only route (405) and the uploaded file is intentionally not persisted. Real browser UX is NOT_RUN and explicitly deferrable per packet EARS. Recommend redirect-based preview or browser validation before release.
- **F7 — PRE-EXISTING MIDDLEWARE NOTE.** `CheckPermission` compares the raw `{branch}` token to `branch_user.branch_id` for non-global users (`CheckPermission.php:34,66-78`); code-based non-numeric URLs are therefore fail-closed, and numeric tokens (incl. `1E0`) map to the same ID as `branch.access`. The UI uses numeric branch IDs; no escalation observed. Not introduced by this packet.
