# Registro de decisiones arquitectónicas
Los ADR posteriores a v2.2 son necesarios solo para puntos abiertos o cambios nuevos. Toda aprobación expresa debe quedar registrada por owner antes de que OpenCode la aplique. Ninguna memoria o comentario sustituye ADR ni specs consolidadas. Los agentes pueden proponer borradores en docs/work, pero no emitir decisiones aprobadas.
